# 6. 기존 API 방식과 자체 운영 방식의 비용 비교

- 작성: 2026-11-19
- 표기: **[실측]** = 기록에서 잰 값 / **[추정]** = 가정으로 계산한 값(가정은 표 아래에 적음)
- 환율 가정 1달러 = 1,400원, 전기요금 가정 170원/kWh(일반용 평균 수준, 실제 계약 단가 확인 필요)

## 6.1 결론 먼저

1. **지금 수치로는 Claude API 비용이 크지 않을 가능성이 높다.** 손님 대화 1건 약 $0.06~0.07(약 90원) [추정, 단가 보정 후]. 월 1,000대화여도 약 9만 원.
2. **"비용이 높다"의 실제 출처를 먼저 확인해야 한다.** 운영 접수는 11-18 기준 아직 0건이고, 시험장 기록에만 **$39.40(약 5.5만 원, 1,956턴)** 이 쓰였다 [실측]. 실제 청구서(Anthropic 콘솔)에서 운영·시험·개발(Claude Code 등) 비중을 나눠 봐야 한다.
3. **가장 싸고 빠른 절감책은 로컬 전환이 아니라 Claude 안에서의 조정** — 11-20 실측: 같은 24문항에서 **Haiku 5.5가 Sonnet 5.5와 같은 24/24 통과에 비용 $0.0238 대 $0.3231(약 1/14)** [실측]. 11-23 여러 턴 확인(회귀 59대화 + 고정 세트 20명)에서도 Sonnet과 거의 같은 품질, **턴당 약 1/11~1/12** [실측]. 교체 시 `max_tokens` 4096 + 도구 반복 한도 4가 같이 필요(MODEL_EVALUATION 5.7).
4. 로컬 LLM은 **새 GPU 서버를 사면 월 고정비(약 29만 원 [추정])가 지금 API 비용보다 크다.** 비용보다 "데이터를 밖으로 안 보냄"과 "직원용 도우미(RAG)"가 로컬의 실제 이점이다.

| 모델 | 입력 | 출력 | 캐시 쓰기(5분) | 캐시 읽기 | 비고 |

| Sonnet 5.5 (현재) | $2 | $10 | $2.50 | **$0.10** | 공식 단가 페이지(2026-11-19 확인). 각주: "Opus 5.5·Sonnet 5.5의 캐시 적중은 기본 입력의 **0.05배**" — 다른 모델의 0.1배 규칙과 다름 |
| 코드 `PRICE`(api/chat.js:25)의 Sonnet 5.5 | $2 | $10 | $2.50 | **$0.20** | **캐시 읽기를 2배로 기록 중** |
| Haiku 5.5 | $0.10 | $0.50 | $0.125 | $0.01 | 프롬프트 10만 토큰 이하 기준(넘으면 $0.50/$2.50) — 공식 페이지 확인 |
| Batch API | 위 단가의 50% (Sonnet 5.5 $1/$5, Haiku 5.5 $0.05/$0.25) | | | | 실시간 대화에는 못 씀(비동기). 시험 재생에는 쓸 수 있음 |

  - 운영 1턴 예시: 입력 109 · 출력 425 · 캐시 읽기 24,050 → 기록 $0.0093 → 공식 단가 재계산 **$0.0069**

- Haiku는 출력 토큰이 Sonnet의 약 1.9배(21,965 대 11,611 — 생각 토큰 포함)인데도 단가 차이로 1/14.

- 로컬 턴당 전기료 [추정]: GPU 사용 시 시스템 약 250W × 턴당 약 4초 ≈ 0.28Wh → 0.05원. 대기 전력이 훨씬 큼(아래 고정비).

가정 [추정]
- A: 대화당 $0.065. A': 대화당 $0.005(11-20 실측 턴당 $0.00088 × 4.7턴 ≈ $0.004보다 약간 높게 잡음, 회귀 검증 전).
- B1: 지금 PC(RTX 2060 SUPER 8GB)를 24시간 켜 둠. 추가 대기 전력 60W × 720시간 ≈ 43kWh ≈ 7,300원 + 사용 전력 → 약 1만 원. **단, Vercel 손님 챗봇이 이 PC에 닿으려면 외부 공개(터널·인증)가 필요하고, PC가 꺼지면 챗봇이 멈춤.** 개발 PC라 운영용으로 부적합.
- B2: 24~32GB VRAM급 GPU 워크스테이션 약 500만 원 / 36개월 = 13.9만 원 + 전기 약 3만 원 + 관리 월 4시간 × 3만 원 = 12만 원 → **약 29만 원/월**. 하드웨어 가격은 견적 받아 확인 필요.
- C: 대화의 40%(간단 FAQ·가격 문의 가정)는 규칙·캐시·로컬로 처리해 대화당 비용 0, 나머지 60%는 Sonnet 대화당 $0.065, 여기에 로컬 고정비 B1 1만 원을 더함(예: 1,000대화 = 600 × $0.065 × 1,400원 + 1만 원 ≈ 6.5만 원). 견적 계산은 어느 쪽이든 기존 엔진.
- 관리 비용(모델 갱신·장애 대응·보안 패치)은 사람 시간이라 표에 "관리"로만 표시. 소규모 회사에서는 이 비용이 API 비용보다 클 수 있음.
