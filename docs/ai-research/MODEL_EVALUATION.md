### 채점 방법과 한계
- 수치 기준: 대화 결과 JSON을 최종 채점기(근거 = 메뉴판 + 규칙 글 + 도구 결과)로 다시 채점한 값. 4b는 실행 당시 채점(최소 주문액 600,000원을 근거로 안 침) 기준으로는 통과 12/24·근거 없는 금액 12/24였음. 9b는 두 기준이 같음.
- 통과 = 오류 없음 + 필요한 도구 호출 + 근거 없는 금액 없음 + 필수 글자 있음 + 금지 글자 없음 + 언어 맞음.
- 근거 = 메뉴판 + 지식 프롬프트 속 숫자 + 그 대화의 도구 결과(부가세 포함·음식값 합계 포함) + 손님이 말한 숫자.
- 한계 ① 지식 프롬프트의 예시 숫자와 우연히 같으면 못 잡음 ② 도구 호출이 temperature 0.3에서 실행마다 달라짐(4B 2/11 ↔ 5/11) → 반복 실행 평균이 필요 ③ 질문 24개는 통계적으로 작음.
- 채점기 자체 결함 2건을 시험 중 발견·수정: JSON 숫자(쉼표 없음)를 못 읽던 것, 최소 주문액 600,000원(규칙 글)을 근거로 안 치던 것. 수정 전 Claude 기존 기록 오탐률 37.5% → 수정 후 4.2%.

## 5.3 해석
- 로컬 4B·9B는 **"규칙이 긴 손님용 도구 호출 대화"에 부적합**. 핵심 실패가 모두 도구 호출(견적·접수)에서 나옴 — 기존 챗봇이 Claude 습관에 맞춰 다듬은 매뉴얼이라는 점도 원인(chatbot-developer 의견과 같음).
- 9B는 금액 환각이 크게 줄지만(11→1) 도구는 여전히 안 부르고, CPU로 넘어가 4배 느림.
- 한국어 품질·안전 거절은 통과 수준 → **역할을 좁힌 직원용 도우미(검색·초안)에는 쓸 만함**(5.4).
